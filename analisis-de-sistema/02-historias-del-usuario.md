# Identificación de Historias de Usuario

**Objetivo:** describir las principales necesidades de los usuarios.[cite: 4] Utilizar el formato:

> Como [actor], quiero [acción], para [beneficio].[cite: 4]

| ID | Historia de usuario |
| :--- | :--- |
| **HU01** | Como cliente, quiero buscar y consultar productos, para encontrar el producto que necesito.[cite: 4] |

| **HU03** | Como cliente, quiero gestionar los productos de mi carrito, para preparar los productos que deseo comprar.[cite: 4] |
