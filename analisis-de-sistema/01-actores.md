# Identificación de Actores

**Objetivo:** determinar quiénes interactúan con el sistema.[cite: 3]

| Actor | ¿Qué necesita realizar? |
| :--- | :--- |
| **Cliente** | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar el pago y consultar sus pedidos.[cite: 3] |
| **Seller** | Ofrecer productos, Registrar productos, actualizar productos, consultar sus productos y gestionar la información relacionada con sus ventas.[cite: 3] |
| **Administrador** | Administrar la plataforma[cite: 3] |
| **Pasarela de pago** | Procesar pagos[cite: 3] |
| **Servicio de envío** | Gestionar información de entrega[cite: 3] |
| **Servicio de Facturación** | Generar comprobantes de pago[cite: 3] |
| **ERP** | Proporcionar información de productos y stock[cite: 3] |
