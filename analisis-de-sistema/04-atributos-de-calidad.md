# Identificación de Atributos de Calidad

**Objetivo:** determinar cómo debe comportarse el sistema, además de qué debe hacer.[cite: 6]

Analizar el siguiente escenario: durante una campaña comercial, el marketplace podría recibir una gran cantidad de usuarios consultando productos y realizando compras simultáneamente.[cite: 6] ¿Qué atributos de calidad resultan importantes? Por ejemplo: rendimiento, disponibilidad, escalabilidad, seguridad y mantenibilidad.[cite: 6]

| ID | Atributo de calidad | Escenario de calidad |
| :--- | :--- | :--- |
| **AC01** | **Rendimiento** | Las consultas de productos y operaciones del carrito deben responder rápidamente incluso cuando exista una alta cantidad de usuarios concurrentes.[cite: 6] |
| **AC02** | **Disponibilidad** | El sistema debe permanecer disponible durante la campaña comercial y permitir que los usuarios realicen sus operaciones.[cite: 6] |
| **AC03** | **Escalabilidad** | El sistema debe poder soportar un incremento de usuarios y solicitudes sin afectar significativamente su funcionamiento.[cite: 6] |
| **AC04** | **Seguridad** | Los datos de los usuarios, cuentas y operaciones de compra deben estar protegidos frente a accesos no autorizados.[cite: 6] |
| **AC05** | **Mantenibilidad** | El sistema debe estar organizado de manera que permita realizar cambios y correcciones sin afectar innecesariamente otras funcionalidades.[cite: 6] |
