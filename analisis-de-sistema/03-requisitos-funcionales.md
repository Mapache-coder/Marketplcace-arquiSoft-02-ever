# Identificación de Requisitos Funcionales

Las historias de usuario permiten identificar las funcionalidades que el sistema debe proporcionar.[cite: 5]

## Requisitos Funcionales

| ID | Requisito funcional |
| :--- | :--- |
| **RF01** | El sistema debe permitir buscar productos mediante criterios de búsqueda.[cite: 5] |
| **RF02** | El sistema debe permitir consultar la información y disponibilidad de los productos.[cite: 5] |
| **RF03** | El sistema debe permitir registrar y actualizar productos en la plataforma.[cite: 5] |
| **RF04** | El sistema debe permitir agregar, modificar y eliminar productos del carrito de compra.[cite: 5] |
| **RF05** | El sistema debe permitir generar un pedido a partir de los productos del carrito.[cite: 5] |
| **RF06** | El sistema debe permitir consultar los pedidos realizados y su estado.[cite: 5] |
| **RF07** | El sistema debe permitir registrar, actualizar y desactivar sellers de la plataforma.[cite: 5] |
| **RF08** | El sistema debe permitir consultar el detalle de un pedido realizado.[cite: 5] |

## Relación entre HU y Requisitos Funcionales

| Historia de usuario | Requisitos funcionales relacionados |
| :--- | :--- |
| **HU01** Buscar y consultar productos | RF01, RF02[cite: 5] |
| **HU02** Gestionar productos | RF03[cite: 5] |
| **HU03** Gestionar carrito | RF04[cite: 5] |
| **HU04** Realizar pedido | RF05, RF08[cite: 5] |
| **HU05** Gestionar sellers | RF07[cite: 5] |
| **HU06** Consultar pedidos | RF06, RF08[cite: 5] |
